# The Element Within

A story-driven, unofficial Avatar-inspired personality quiz. Twelve choices explore instinct, pressure, and purpose, revealing a primary elemental affinity and secondary influences.

## Play

Open **The Element Within.html** in a browser. This single-file edition contains the complete layout and quiz logic. Internet access loads Google Fonts and the Helios Valley cover images; the quiz itself also works offline with fallback fonts.

For static hosting, publish the contents of `dist/`. No dependencies, account, or build step required.

## Features

- Four elemental profiles with strengths, growth prompts, and bending styles.
- Balanced answer positions, tie-breaking crossroads, review, restart, and result copying.
- Browser-local progress storage; no quiz answers sent to a server.
- Responsive layout, keyboard controls, and reduced-motion support.
- Clearly labeled Helios Valley coloring book advertisements on welcome and results screens. No advertising trackers or pop-ups.

## Editing

Edit `dist/app.js`, `dist/style.css`, and `dist/index.html`. Run `node build.mjs` to refresh the standalone HTML. Run `node --check dist/app.js` to check JavaScript syntax.

Promotions link to https://www.atlasvalleybooks.com/helios/ and https://www.atlasvalleybooks.com/helios/halloween/. Covers remain hosted on the owner's website.

Independent fan experience, not affiliated with Avatar's creators. Quiz outcomes are entertainment and reflection, not a validated personality assessment.
